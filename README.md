Daniel’s Backyard Wiffleball Database (Final Project)


Overview -
Daniel’s Backyard Wiffleball Database is a Python-based stat tracking system designed for managing backyard wiffleball   leagues. The project allows users to create teams and players, record games, edit stats, search player/team statistics, and  display team rosters.


The project includes two versions -   
Text-Based Version: Runs entirely in the terminal/command prompt.  
GUI Version: Uses customtkinter to provide a modern graphical interface.  


Libraries that must be installed -   
JSON: All data is stored in a stats.json file allowing league information to save between everytime the code is ran.  
customTKinter: Allows for the creation of GUIs for a better user experience.  


Features -  
Team Management  
Create teams  
Store rosters  
View team rosters  
Player Management  
Create players  
Assign players to teams  
Store individual game logs  
Game Tracking  
Record complete game results  
Track offensive and pitching statistics  
Save stats by date and game number  
Editing System  
Edit previously entered player stats  


Automatically Updating Stats -  
Batting Average  
On Base Percentage  
Strikeout Percentage  
Walk Percentage  
Home Runs  
Pitching Strike Percentage  
Pitching Walk Percentage  
Win/Loss Record  
Team Batting Average  
Team OBP  
Team Strikeout %  
Team Walk %  
Total extra-base hits
